# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

QuranGraph is a static website hosted via Cloudflare Workers Static Assets with no user accounts, passwords, personal data collection, or dynamic backend databases at runtime.

However, if you discover any security, dependency, or content integrity issue, please report it privately:

- **Email**: Send details to `iliassami57@gmail.com` with the subject `[QuranGraph Security]`.
- **Response Time**: We acknowledge reports within 48 hours and work to deploy remediation promptly.

Please do not open public GitHub issues for security vulnerabilities until a patch has been published.
